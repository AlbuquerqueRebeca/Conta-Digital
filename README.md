# Conta Digital


Este projeto foi desenvolvido como parte de um desafio oferecido pela DIO.
Um sistem que oferece aos clientes dois tipo de contas (Corrente e Poupança), que possuem funcionalidades de depósito, saque e tranferência (entre contas da mesma instituição).

#### Objetivo:
Implementar uma solução orientada a objetos em java, aplicando os conceitos de abstração, herança, polimorfismo e encapsulamento.

------------------------------------------------------------------------------
#### Funcionalidades: 
- Criação de contas Corrente e Poupança
- Operações básicas:
- Deposito
- Saque
- Transferencia entre contas da mesma instituição


----------------------------------------------------------------------------

### Adicionais: 
Álem das funcionalidades solicitadas pela DIO, adicionei recursos extras para enriquecer o sistema:

- Nome do Titular
- Número da conta
- Agência
- Saldo

---------------------------------------------------------------------------------

#### Conceitos de POO

- Abstração
- Classe Conta representa uma conta bancária genérica, com atributos coomo numero, agencia, nomecliente e saldo.

- Herança
- Polimorfismo
- O método fazerTransferencia aceita um objetivo conta como argumento, permitindo trabalhar com qualquer instância de conta ou suas subclasses

- Encapsulamento
- Atibutos declarados como rpivate, como métodos públicos para manipulção segura de dados.


-----------------------------------------------------------------------------------------------------------------------------------------------

#### Tecnologias Utilizadas

- Java 17
- Programação orientada a objetos (POO)
- Entrada dados via terminal com scanner
